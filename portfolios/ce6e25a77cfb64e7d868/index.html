الخبرة

مسيرتي المهنية

- تطوير متجر إلكتروني Sochic باستخدام Flutter، حيث صممت واجهات المستخدم المتجاوبة ودمجت بوابات دفع إلكترونية لتحسين تجربة التسوق.
- إنشاء تطبيق تعليمي تفاعلي يتيح للطلاب الوصول إلى المحتوى الدراسي وإجراء الاختبارات، مع التركيز على الأداء السهل والاستجابة السريعة.
- تصميم وتطوير واجهة برمجة تطبيقات (Web API) باستخدام ASP.NET Core لمشروع Code Clash، تضمنت تنفيذ نقاط النهاية RESTful، وتوثيق البيانات، وتحسين أمان التطبيق. — - العمل على تحسين أداء التطبيقات عبر تقليل زمن الاستجابة واستخدام تقنيات التخزين المؤقت المناسبة.
